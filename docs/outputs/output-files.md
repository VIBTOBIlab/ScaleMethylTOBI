# Output files

All results are written to the folder set by `--outdir` (`ScaleMethyl.out` by default). Most users only need the reports in `report/` and the single-cell outputs in `samples/`.

In the paths below, `<sample>` is a sample name from samples.csv, `<well>` a Tn5 well (e.g. `1A01`), `<libName>` a library name and `<context>` `CG` or `CH`.

## samples/: single-cell results

| File                                                            | Description                                                                                                                                                                                                                          |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<sample>.allCells.csv`                                         | Metrics for every cell barcode: `cell_id` (the barcode sequences joined with `+`), read and coverage counts, global CG/CH methylation, `pass` (passing cell or not) and the well of each barcode (`i7_well`, `i5_well`, `tgmt_well`) |
| `genome_bin_matrix/<sample>.CG.score.mtx.gz`                    | CG methylation score per genome bin and passing cell (Matrix Market)                                                                                                                                                                 |
| `genome_bin_matrix/<sample>.CH.mtx.gz`                          | CH methylation rate per genome bin and passing cell (only with `calculate_ch: true`)                                                                                                                                                 |
| `genome_bin_matrix/<sample>.<context>.features.tsv`             | Genome bins (matrix rows)                                                                                                                                                                                                            |
| `genome_bin_matrix/<sample>.barcodes.tsv`                       | Cell barcodes of the passing cells (matrix columns)                                                                                                                                                                                  |
| `genome_bin_matrix/genome_tiles_<context>.bed`, `chrom.sizes`   | Bins and chromosome sizes generated by the run                                                                                                                                                                                       |
| `methylation_coverage/cov/<sample>/<context>/`                  | Per-cell bismark `.cov.gz` files (`cov_out`)                                                                                                                                                                                         |
| `methylation_coverage/allc/<sample>/<context>/`                 | Per-cell ALLC files with tabix index (`allc_out`)                                                                                                                                                                                    |
| `methylation_coverage/amethyst/<sample>/<sample>.<well>_cov.h5` | Amethyst `.h5` files, one per Tn5 well (`amethyst_out`)                                                                                                                                                                              |

### Genome-bin matrices

Rows are genome bins (`features.tsv`) and columns are cells (`barcodes.tsv`). They can be loaded into Seurat, Scanpy, Amethyst or similar tools for clustering and visualisation.

| Matrix                     | Values                                                                                                                                                                                                                                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<sample>.CG.score.mtx.gz` | With _cellGlobalMet_ the global CG methylation of the cell and _diff_ = (methylation rate of the bin - _cellGlobalMet_): _score_ = _diff_ / (1 - _cellGlobalMet_) if _diff_ > 0, otherwise _diff_ / _cellGlobalMet_. Scores range from -1 (unmethylated) to 1 (methylated); bins without coverage are 0, which can give cleaner clustering. |
| `<sample>.CH.mtx.gz`       | CH methylation rate (methylated / covered CH), from 0 to 1                                                                                                                                                                                                                                                                                  |

The bins are set by `window_tile_size_cg` / `window_tile_size_ch` or by the `genomeTiles` / `genomeTilesCH` BED files in [genome.json](../user-guide/reference-genomes.md#genome-bins-for-the-matrices).

### Amethyst files

Each `.h5` file holds the passing cells of one sample and Tn5 well, with one group per cell: `/CG/<cell_id>/1` and `/CH/<cell_id>/1` contain the base-level calls (`chr`, `pos`, `pct`, `t`, `c`). Load the whole `samples/` folder in R with Amethyst:

```r
obj <- createScaleObject(directory = "ScaleMethyl.out/samples", genomeMatrices = c("CG.score"))
```

## report/: QC reports

| File                                                                         | Description                                                                                                       |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `report/sample_reports/<sample>/<sample>.report.html`                        | Interactive report per sample                                                                                     |
| `report/sample_reports/<sample>/csv/`                                        | Sample metrics as csv, including `<sample>.report_clusters.tsv` (cluster of each passing cell in the report UMAP) |
| `report/sample_reports/<sample>/png/`                                        | Report figures                                                                                                    |
| `report/library_report/<libName>/library.<libName>.report.html`              | Barcode and demultiplexing statistics for a whole library                                                         |
| `report/library_report/<libName>/csv/<libName>.combinedPassingCellStats.csv` | Key metrics of the passing cells of the library                                                                   |

See [QC reports](qc-reports.md) for what the reports show.

## barcodes/: demultiplexing

| File                                               | Description                                                                                                              |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `<libName>.metrics.json`                           | Barcode statistics of the whole library (merged over all demultiplexing jobs); see [Barcode metrics](barcode-metrics.md) |
| `<libName>.<n>.demux/metrics.json`                 | Barcode statistics of one demultiplexing job (one set of input fastq files)                                              |
| `<libName>.<n>.demux/barcode_counts.<barcode>.tsv` | Reads per barcode (one file per barcode in the library structure, e.g. `i7`, `i5`, `tgmt`)                               |
| `<libName>.<n>.demux/*.fastq.gz`                   | Demultiplexed sample fastq files, only with `fastq_out: true`                                                            |

## fastq/: fastq generation and trimming

| File                                                   | Description                                                                    |
| ------------------------------------------------------ | ------------------------------------------------------------------------------ |
| `samplesheet.csv`                                      | bcl-convert samplesheet generated by the workflow (run-folder input)           |
| `Reports/`                                             | bcl-convert reports, including the demultiplexing statistics                   |
| `fastqc/*.html`                                        | [FastQC](https://github.com/s-andrews/FastQC) report for each input fastq file |
| `trim/<sample>.<well>/<sample>.<well>.trim_stats.json` | Trimming statistics                                                            |
| `*.fastq.gz`, `trim/*/*.fq.gz`                         | bcl-convert and trimmed fastq files, only with `fastq_out` / `trim_out`        |

## alignments/: alignment and deduplication

| File                                                      | Description                                                                              |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `bam/<sample>.<well>/<sample>.<well>.bam`                 | Aligned reads, only with `bam_out: true`                                                 |
| `dedup/<sample>.<well>/<sample>.<well>.dedup.bam`         | Deduplicated reads with cell barcodes in the read names, only with `bam_dedup_out: true` |
| `dedup/<sample>.<well>/<sample>.<well>.cell_stats.tsv`    | Reads per cell barcode                                                                   |
| `dedup/<sample>.<well>/<sample>.<well>.cellInfo.txt`      | CG, CH and total coverage per cell barcode                                               |
| `dedup/<sample>.<well>/<sample>.<well>.dedup_stats.tsv`   | Overall deduplication statistics                                                         |
| `dedup/<sample>.<well>/<sample>.<well>.fragment_hist.tsv` | Fragment size histogram                                                                  |

## Other folders

| Folder / file            | Description                                                                 |
| ------------------------ | --------------------------------------------------------------------------- |
| `matrix_generation/`     | Per-well methylation calls (`.parquet`), needed for `start_post_extraction` |
| `metrics_for_reporting/` | Per-sample metrics, needed for `reporting_only`                             |
| `bamMerge/`              | Merged BAM files when starting from BAM files with `bam_merge_out: true`    |
| `samples.csv`            | The sample table as used by the run (with defaults filled in)               |
| `workflow_info.json`     | Command, parameters, reference and version of the run                       |
| `pipeline_info/`         | Nextflow execution report, timeline, trace and DAG, the parameters (`params_*.json`) and the software versions (`scalemethyltobi_software_versions.yml`) |
